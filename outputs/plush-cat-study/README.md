# 软糯虎斑 · 动画样片

使用 Godot 4.7.2 打开 project.godot，按 F5 播放。单只虎斑、约6秒，用于确认“软糯Q弹玩偶猫”的动作方向。本工程独立于现有消除游戏，尚未替换游戏内演出，也尚未扩展九种猫。

## 看什么

0–1.08秒：呼吸、望向猫粮、起步前压低蓄力。
1.08–2.1秒：轻跳两步，身体压缩拉伸，落地回弹，头部与耳朵滞后。
2.1–4.6秒：低头切换进食姿态、小幅咀嚼、猫粮逐渐减少。
4.6–6秒：抬头弹性恢复、舔嘴、尾巴摆动和满足反馈。

眼睛保持常睁、不眨眼；未低头时保留鼠标视线响应。预览动画固定视线以方便比较动作。

## 播放控制

重播、暂停/继续、0.65倍慢放；底部时间轴可拖动检查任意姿态。动画默认播放一次并停留在结束姿态，点重播即可再次观看。

## 制作结构

GPT Image 制作身体、尾巴和低头头像，沿用原正面头像；真实透明底。素材位于 assets/，具体生成提示词同目录。没有使用 AI 生成视频直接替代可交互动画。

scenes/study.tscn：主场景，包含 CatRig 与 AnimationPlayer。
animations/meal.tres：六秒时间轴，在编辑器中查看、调整。
scripts/cat_rig.gd：分层身体、头、尾及耳部局部网格变形，使用衰减回弹曲线。
scripts/face.gd：常睁眼视线和舔嘴表情。
scripts/study.gd：食盆、播放控制与说明界面。

这是“分层贴图 + 局部网格变形 + 程序曲线”的轻量绑定样片，没有依赖 Spine。时间轴驱动 CatRig.pose_time，具体动作幅度和时间段在 cat_rig.gd 内。身体和前爪目前仍是一张图；如果方向确认后需要走路和伸爪，再拆分四肢，而不是现在扩建全套角色。

## 已验证

使用实际 OpenGL 渲染器输出144帧，720×480、24fps、6秒；检查期待、跳跃、进食、满足关键姿态；验证重播、暂停、慢放、拖动时间轴和素材透明通道。样片只验证动作方向，尚未完成手机小尺寸呈现及九种花色适配。

后续接回游戏时，应以动画完成信号控制下一关，而不是沿用旧演出的固定3.1秒等待。
